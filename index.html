Scrolly Kirk

Instagram with our modifications: a per-video volume control and a phone-style desktop app.

Use it in your normal browser (Chrome, Edge, Brave)

  1. Download or clone the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the extension folder.
  4. Open instagram.com. Hover over a video to see its volume bar.

Use the desktop app

Run npm install once, then npm start (on Windows PowerShell: npm.cmd start).
