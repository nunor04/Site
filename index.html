What you get

Phone-style layout

Instagram's mobile layout in a centered phone column, even in full screen.

🔊

Per-video volume

A slim bar for each video that appears only when you hover it. Keyboard friendly.

🔥

Most viewed

Sort any profile's reels from most to least viewed, in one click.

🔑

Stays logged in

The desktop app remembers your account between launches.

Get the app or extension

Desktop app: run npm install then npm start, or build the single .exe with npm run dist.

Browser extension: open chrome://extensions, turn on Developer mode, click Load unpacked and choose the extension folder of the repository.
